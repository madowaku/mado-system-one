# System One docs

This directory contains the three canonical design documents for MADO System One.

1. **MADO_SYSTEM_ONE_ARCHITECTURE.md v0.2**  
   Stable boundaries, providers, probability semantics, typed action loop, semantic sieve, policy and verification.

2. **MADO_SYSTEM_ONE_PATTERN_ATLAS.md v0.1**  
   Living catalog of ROUTE / COMPUTE / RANK / GATE / ACT / SCORE / ABSTAIN / SIEVE / WALK / VERIFY.

3. **MADO_SYSTEM_ONE_OPERATIONS.md v0.1**  
   OFF → SHADOW → CALIBRATING → ACTIVE_LIMITED → ACTIVE → ACTIVE_WITH_ESCALATION → SPECIALIZING → LOCALIZED.

Architecture should move slowly. The Pattern Atlas can absorb fast-moving community experiments. Operations defines how decision surfaces earn trust in production.
